# 제3차 슈퍼로봇대전 α 한글판 확장 패치 (SRWA3 KR Plus)

PS2 「제3차 슈퍼로봇대전 α -종언의 은하로-」(SLPS-25537) **한글패치 적용본**에 덧씌우는 비공식 확장 패치입니다.
ISO는 포함하지 않으며, xdelta 패치만 배포합니다.

> **v0.2부터 공식 한글패치 최신판(에뮬레이터용 v1.1.2s)을 기준으로 합니다.** 내용은 v0.1과 같고, 바탕이 되는 한글판만 바뀌었습니다(한글 타이틀 로고·옵션 메뉴·게임 화면 능력치/전투 표시 글자 그림 포함).
> 예전 한글판에 맞춘 v0.1은 이전 릴리스에 그대로 남겨 둡니다.

> ## ⚠️ 패치 적용 순서 (꼭 지켜 주세요)
> **① 공식 한글패치 v1.1.2s(에뮬레이터용) → ② 기본 패치(`SRWA3_KR_Plus_base.xdelta`) → ③ 확장 패치(`SRWA3_KR_Plus_a2units_test.xdelta`, 선택)**
>
> - **확장 패치는 단독으로 쓸 수 없습니다.** 반드시 **기본 패치를 먼저 적용한 ISO**에 덧씌워야 합니다.
> - 한글판 ISO에 확장 패치를 바로 적용하거나, 확장 패치를 먼저 적용하면 **xdelta가 오류를 내고 적용되지 않습니다**(입력 파일 불일치). ISO가 망가진 것이 아니니 순서대로 다시 적용하면 됩니다.
> - 단계마다 결과 SHA1을 확인하세요: ① `f165ee2f…` → ② `d2e70bf5…` → ③ `4cc671aa…`

## 구성

| 파일 | 입력 | 결과 | 내용 |
|---|---|---|---|
| `SRWA3_KR_Plus_base.xdelta` | 공식 한글패치 v1.1.2s 적용 ISO | 기본판 | 3차α 내부 자원(미사용·숨겨진 데이터) 활용과 합류·지급 체계 정리 |
| `SRWA3_KR_Plus_a2units_test.xdelta` | 기본판 | 확장판(시험) | 2차α 기체 이식 — **시험판, 실플레이 지양** |

### 기본 패치 주요 내용
- 작품별 기체 지급: 각 작품 캐릭터가 정식 합류할 때 그 작품의 기체를 함께 지급합니다(원작 합류 시점 기준, 주인공 루트별).
- 그룬가스트 삼식·휴케바인 Mk-III 트롬베: 28화에 류세이 합류와 함께 지급합니다.
- 용호왕·호룡왕: 각 루트의 후속기 등장 시점에 지급합니다. 슈퍼계 여주인공 루트는 빈 기체로, 다른 루트는 쿠스하·브리트와 함께 들어옵니다.
- 하만(큐베레이)·샤아(사자비): ZZ 멤버·역습의 샤아 멤버가 합류할 때 함께 합류합니다. 2차α의 전투 대사·음성을 이식했습니다.
- 쿠스하·브리트의 용호왕·호룡왕 탑승 시 전투 대사(2차α 대사 병합)
- 갈아타기 등급 조정: 오리지널 캐릭터와 오리지널계 로봇, 용호왕 계열 전용 등급
- 지형 이름 번역 등 미번역 일부 보완
- 시나리오 플래그 충돌 수정

## 적용 방법
1. **원본 ISO와 메모리카드를 먼저 백업하세요.**
2. 입력 ISO를 준비합니다: 일본판 원본에 **공식 한글패치 v1.1.2s(에뮬레이터용)**를 적용한 ISO입니다.
   - 공식 한글패치 배포처: https://github.com/z3oo3z/PS2-SRW3thAlpha-KPatch (`3alpha_PS2emul_v1.1.2s.7z`)
   - 일본판 원본 MD5: `da1cfc296bd896e88dddcccc374d4b08`
   - 한글패치 적용 결과 MD5: `c1c446a5b3d023944271ec521b13e07e` / SHA1: `f165ee2f49efebb9d2219126c7e55e49e526e726` (4,285,595,648 바이트)
   - 한글패치와 한글판 ISO는 이 저장소에서 배포하지 않습니다. 공식 배포처의 안내와 조건을 따라 주세요.
3. xdelta3(또는 xdelta UI / Delta Patcher)로 적용합니다. 결과는 반드시 **새 파일 이름**으로 저장하세요.
   - 2026-11-10: 패치 파일을 LZMA 압축 없이 다시 만들었습니다(내용·결과 SHA1 동일). 그 전에 받은 파일이 Delta Patcher 등에서 적용되지 않았다면 새로 받아 주세요.
   ```
   xdelta3 -d -s "원본.iso" SRWA3_KR_Plus_base.xdelta "SRWA3_KR_Plus.iso"
   ```
4. 결과 SHA1을 확인합니다: `d2e70bf585a92fd010a367afe1d0e312b28d69ac`
5. 에뮬레이터를 완전히 끈 뒤 새 ISO로 부팅하고, 게임 안의 LOAD를 사용하세요. **이전 버전의 세이브스테이트는 사용하지 마세요.**

## 주의
- 실기 검증 범위가 제한적인 시험 배포입니다. 모든 루트·분기를 끝까지 확인한 것은 아닙니다.
- 기존 세이브는 그대로 불러올 수 있도록 만들었지만, 첫 저장은 다른 슬롯에 해 두는 것을 권장합니다.
- 한글패치 원본의 저작권은 원 제작자에게 있습니다. 이 패치는 한글패치 적용본을 전제로 합니다.

## 알려진 부족한 점
- **실기 검증이 제한적입니다.** 네 주인공 루트와 분기를 모두 끝까지 플레이해 확인하지 못했습니다. 특히 작품별 기체 지급, 용호왕 계열 지급, 하만·샤아 합류 시점은 정적 분석 기준으로 맞췄습니다.
- **갈아타기 후 원래 기체로 돌아가지 못하는 문제**가 있습니다. 다른 기체로 갈아탄 파일럿은 자기 원래 기체 목록에 다시 나타나지 않습니다. 지금은 임시 조치로, 원작 전용기 계열을 별도 등급(9·14)으로 묶어 두었습니다.
- 서브 파일럿 좌석의 갈아타기 동작과 반프레이오스 같은 멀티 파일럿 기체는 손대지 않았습니다.
- 굉룡改·뇌호王改 시기의 쿠스하·브리트는 서브 좌석을 지정하는 화면이 없어서, 용호왕 팀으로 깔끔하게 묶을 수 없습니다.
- 원래 한글패치의 미번역 부분이 일부 남아 있습니다. 기초 강좌(KURO) 본문, 인물사전 일부, 이름 입력 가나표 등입니다(공식 v1.1.2s에서도 그대로입니다).
- 맵 아이콘 캐시는 원본과 같은 상태(여유 1칸)입니다. 맵 아이콘을 추가하는 다른 개조와 함께 쓰면 일부 맵에서 멈출 수 있습니다.

## 고칠 예정
1. ~~메모리 확장~~ · ~~맵 아이콘 상주 방식 개선~~ · ~~2차α 기체 이식 확장 패치~~ → 확장 시험판 v0.2.1에 반영(아래)
2. 메모리 확장·아이콘 개선을 기본 패치에도 반영할지 검토
3. 갈아타기 후 원래 기체로 돌아가는 처리(메모리 확장 후 코드 수정)
4. 환장(換裝) 표 확장, 2차α BGM 추가 검토

## 확장 패치(2차α 기체 이식) — 시험판

> ⚠ **실플레이는 가급적 피해 주세요.** 기능 확인·피드백용 시험판입니다. 진행 중인 본 세이브로 플레이하지 말고, 반드시 별도의 메모리카드나 복사본으로 시험해 주세요.

### 내용
- 2차α의 기체 데이터(능력치·무장·전투 연출·맵 아이콘)를 3차α의 예비 기체 칸에 이식했습니다.
  - 건담 F91, 크로스본 건담 X1·X2·X3: 28화 류세이 합류와 함께 지급
  - 윙건담(EW)·윙건담(버드 형태): 히이로 합류와 함께 지급(루트별)
- 윙건담(EW)·버드 형태는 **각자의 2차α 맵 아이콘**을 씁니다.
- **v0.2.1부터 메모리 확장과 맵 아이콘 개선이 들어갔습니다.**
  - 메모리 확장: 힙 꼭대기 256KB를 전용 구역으로 확보해, 새 코드와 늘어난 아이콘 표를 넣었습니다.
  - 맵 아이콘: 아군 기체 아이콘을 전부 미리 올려 두던 방식을 «보유 기체만 + 필요할 때 다시 올림」으로 바꿨습니다. 27화 기준 실측 사용량은 256칸 중 약 45칸입니다.
  - 캐시 마지막 칸(255번)은 원본처럼 쓰지 않습니다. 칸이 모자라면 쓰이지 않는 아이콘을 비우고 다시 올립니다.
  - → v0.2-a2-test에서 **27화 Z마스터 아이콘이 엉뚱하게 나오던 문제가 해결**되었습니다(실기 확인).

### 적용 방법
> ⚠️ **기본 패치 → 확장 패치 순서입니다.** 확장 패치만 따로, 또는 먼저 적용하면 적용되지 않습니다.

1. **기본 패치를 먼저 적용한 ISO**(SHA1 `d2e70bf585a92fd010a367afe1d0e312b28d69ac`)를 준비합니다.
2. 확장 패치를 적용하고 새 이름으로 저장합니다.
   ```
   xdelta3 -d -s "SRWA3_KR_Plus.iso" SRWA3_KR_Plus_a2units_test.xdelta "SRWA3_KR_Plus_a2units.iso"
   ```
3. 결과 SHA1: `4cc671aa697bc14eb4881ada1305e8a9c1df6ffb`

### 시험판의 위험과 한계
- **실기 검증이 제한적입니다.** 27화 전·후반, 29화 진입, 윙건담 두 형태(지급·변형), 이식 건담의 갈아타기는 확인했습니다. 그 밖의 장면과 루트는 확인하지 못했습니다.
- 메모리 확장은 게임의 힙을 약 1.1% 줄입니다. 지금까지는 문제가 없었지만, 오래 플레이하다 「Memory allocation failure」나 멈춤이 생기면 알려 주세요.
- 이 시험판의 ELF는 구조가 바뀌어(프로그램 구역 추가) 실기(PS2 본체)에서는 확인하지 않았습니다. PCSX2 사용을 전제로 합니다.
- 윙건담의 맵 병기는 연출 데이터가 없어 ZZ 건담의 하이 메가 캐논 연출로 대체했습니다.
- 결과 ISO는 약 5.25GB로, DVD-5(4.7GB)보다 큽니다. 에뮬레이터 사용을 전제로 합니다.
- 확장판 세이브를 기본판에서 불러오면 이식 기체 칸이 비정상으로 보일 수 있습니다. 확장판 세이브는 따로 관리해 주세요.
- v0.2-a2-test(이전 시험판)의 세이브는 그대로 불러올 수 있습니다(세이브 형식 변경 없음).
