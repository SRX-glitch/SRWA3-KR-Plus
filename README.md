# 제3차 슈퍼로봇대전 α 한글판 확장 패치 (SRWA3 KR Plus)

PS2 「제3차 슈퍼로봇대전 α -종언의 은하로-」(SLPS-25537) **한글패치 적용본**에 덧씌우는 비공식 확장 패치입니다.
ISO는 포함하지 않으며, xdelta 패치만 배포합니다.

## 받을 파일

| 파일 | 현재 버전 | 무엇인가 |
|---|---|---|
| `SRWA3_KR_Plus_base.xdelta` | **v0.3.1** | **기본 패치.** 3차α 안에 숨어 있던 자원 활용, 합류·지급 체계 정리 |
| `SRWA3_KR_Plus_a2units_test.xdelta` | **v0.5 (시험판)** | **확장 패치.** 2차α 기체·브레인 파워드·BGM 이식. 선택 사항이며 실플레이는 권하지 않습니다 |

두 파일 모두 [Releases](https://github.com/SRX-glitch/SRWA3-KR-Plus/releases)에서 받습니다.

## ⚠️ 적용 순서 (꼭 지켜 주세요)

**① 공식 한글패치 v1.1.2s(에뮬레이터용) → ② 기본 패치 → ③ 확장 패치(선택)**

- 확장 패치는 **기본 패치를 적용한 ISO에만** 적용됩니다. 한글판 ISO에 바로 적용하면 xdelta가 오류를 냅니다.
- 순서를 틀려도 ISO가 망가지지는 않습니다. 순서대로 다시 적용하면 됩니다.
- 확장 패치를 새 버전으로 바꿀 때도 **기본 패치를 적용한 ISO**에서 다시 시작합니다(예전 확장판 위에 덧씌우지 않습니다).
- **확장 패치 v0.5는 기본 패치 v0.3.1 위에만 적용됩니다.** 예전 기본 패치(v0.3 이하)를 쓰고 있었다면 한글판 ISO에 기본 패치 v0.3.1부터 다시 적용해 주세요.

| 단계 | 결과 ISO의 SHA1 |
|---|---|
| ① 한글패치 적용 | `f165ee2f49efebb9d2219126c7e55e49e526e726` |
| ② 기본 패치 v0.3.1 적용 | `bb8c5d857a4fd7cffb39d798bff1248573879b0d` |
| ③ 확장 패치 v0.5 적용 | `56715caada88e2cc349160d5e6b3da3a95bdbc3e` |

## 적용 방법

1. **원본 ISO와 메모리카드를 먼저 백업합니다.**
2. 입력 ISO를 준비합니다. 일본판 원본에 **공식 한글패치 v1.1.2s(에뮬레이터용)**를 적용한 ISO입니다.
   - 공식 한글패치: https://github.com/z3oo3z/PS2-SRW3thAlpha-KPatch (`3alpha_PS2emul_v1.1.2s.7z`)
   - 일본판 원본 MD5: `da1cfc296bd896e88dddcccc374d4b08`
   - 한글패치 적용 결과 MD5: `c1c446a5b3d023944271ec521b13e07e` (4,285,595,648 바이트)
   - 한글패치와 한글판 ISO는 이 저장소에서 배포하지 않습니다. 공식 배포처의 안내를 따라 주세요.
3. 기본 패치를 적용합니다. 결과는 **새 파일 이름**으로 저장합니다.
   ```
   xdelta3 -d -s "한글판.iso" SRWA3_KR_Plus_base.xdelta "SRWA3_KR_Plus.iso"
   ```
4. (선택) 확장 패치를 적용합니다.
   ```
   xdelta3 -d -s "SRWA3_KR_Plus.iso" SRWA3_KR_Plus_a2units_test.xdelta "SRWA3_KR_Plus_a2units.iso"
   ```
5. 위 표의 SHA1과 맞는지 확인합니다.
6. 에뮬레이터를 완전히 끈 뒤 새 ISO로 부팅하고, 게임 안의 LOAD로 불러옵니다. **다른 버전에서 만든 세이브스테이트는 쓰지 마세요.**

xdelta3 대신 xdelta UI나 Delta Patcher를 써도 됩니다.

### 적용이 안 될 때

- **checksum mismatch / 입력 파일 불일치**: 입력 ISO가 다릅니다. 위 표의 SHA1(또는 한글판 MD5)을 확인하세요. 실기(PS2)용 한글패치로 만든 ISO에는 적용되지 않습니다.
- **2026-11-10 이전에 받은 패치 파일**은 입력이 맞아도 일부 도구에서 같은 오류가 날 수 있었습니다. 패치를 새로 받아 주세요.

## 기본 패치 (v0.3.1)

- **작품별 기체 지급**: 각 작품 캐릭터가 정식 합류할 때 그 작품의 기체를 함께 지급합니다(원작 합류 시점, 주인공 루트별).
- **그룬가스트 삼식·휴케바인 Mk-III 트롬베**: 28화 류세이 합류와 함께 지급합니다.
- **용호왕·호룡왕**: 각 루트의 후속기 등장 시점에 지급합니다. 슈퍼계 여주인공 루트는 빈 기체로, 다른 루트는 쿠스하·브리트와 함께 들어옵니다.
- **하만(큐베레이)·샤아(사자비)**: ZZ 멤버·역습의 샤아 멤버가 합류할 때 함께 합류합니다. 2차α의 전투 대사·음성을 이식했습니다.
- 쿠스하·브리트가 용호왕·호룡왕에 탔을 때의 전투 대사(2차α 대사 병합)
- 갈아타기 등급 조정: 오리지널 캐릭터와 오리지널계 로봇, 용호왕 계열 전용 등급
- 지형 이름 등 미번역 일부 보완, 시나리오 플래그 충돌 수정

- **초호기 F형 장비의 합체공격**: F형 장비가 옆에 있어도 이호기가 유니존 킥을, 이호기·영호기가 EVA 일제사격을 쓸 수 있습니다. F형 장비 자신의 무기 목록에는 합체공격이 없습니다.
- **곡 추가·조정**: 사운드 셀렉트에 2차α의 미사용곡 「Trombe!　Ver.R（α２）」와 더블제타 곡 「애니메가　아니야」를 추가했고, 3차α에 들어 있지만 목록에 나오지 않던 「Trombe!　Ver.R」도 나오게 했습니다. 휴케바인 Mk-III 트롬베의 기체 곡은 「Trombe!　Ver.R」로 바꿨습니다. 2차α에서 옮긴 곡의 음량을 약 15% 올렸습니다.
- **분기 처리**: 이야기에 따라 부대를 떠나는 것은 원작 파일럿뿐입니다. 추가 기체와 추가 파일럿은 항상 남고, 떠나는 원작 파일럿이 추가 기체에 타고 있었다면 내리기만 합니다. 부대에 없는 레첼이 휴케바인 Mk-III 트롬베에 탄 채로 보이던 문제도 이 처리로 고쳤습니다.
- **원작 등장 화 처리**
  - 하이넬·리히텔은 원작에서 적이나 NPC로 나오는 39~42화 동안 자리를 비웁니다(38화 클리어 때 빠지고 42화 클리어 때 복귀). 하이넬은 원작과 달리 46화 뒤에도 남습니다.
  - 분돌함은 37화와 47화의 원작 합류·이탈을 없애고 계속 남게 했습니다. 맵이 분돌함을 직접 배치하는 47화의 다른 맵과 최종화 일부 맵에서는 자리를 비우고, 그 맵을 클리어하면 돌아옵니다.
- **전투 대사 수정**: 무기 대사가 기합이나 짧은 외침뿐인 경우 공격 시작 대사가 나오지 않던 문제를 고쳤습니다(쿠쿠루의 비미무·황천무, 퀘스의 판넬 등).
- **아이콘 수정**: 마더 뱅가드, 마가루가, 야크트 도가, 바잠, X1·X2 망토 형태의 맵 아이콘이 다른 기체의 것으로 나오던 문제를 고쳤습니다.

## 알려진 문제

- **슈퍼계 루트에서 받는 하이페리온**은 v0.3.1부터 알테리온(CF·DF)·베가리온과 함께 들어와 분리할 수 있습니다. 원작과 같이 맵을 클리어하면 분리 상태로 돌아갑니다. 슈퍼계 루트에서의 분리·재합체는 일부 구간에서만 확인했으니, 분리를 누르기 전에 세이브해 두세요.
- **네 주인공 루트와 분기를 모두 플레이해 확인하지 못했습니다.** 작품별 기체 지급, 용호왕 계열 지급, 하만·샤아 합류 시점은 정적 분석 기준으로 맞췄습니다.
- **갈아탄 뒤 원래 기체로 돌아가지 못합니다.** 다른 기체로 갈아탄 파일럿은 자기 원래 기체 목록에 다시 나타나지 않습니다. 임시 조치로 원작 전용기 계열을 별도 등급으로 묶어 두었습니다.
- 서브 파일럿 좌석의 갈아타기와 반프레이오스 같은 멀티 파일럿 기체는 손대지 않았습니다.
- 굉룡改·뇌호王改 시기의 쿠스하·브리트는 서브 좌석을 지정하는 화면이 없어, 용호왕 팀으로 깔끔하게 묶을 수 없습니다.
- 한글패치의 미번역 부분이 일부 남아 있습니다(기초 강좌 본문, 인물사전 일부, 이름 입력 가나표 등. 공식 v1.1.2s에서도 그대로입니다).
- 기본판의 맵 아이콘 캐시는 원본과 같은 상태(여유 1칸)입니다. 맵 아이콘을 추가하는 다른 개조와 함께 쓰면 일부 맵에서 멈출 수 있습니다. 확장판에서는 개선돼 있습니다.
